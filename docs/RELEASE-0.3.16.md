## 用时记 0.3.16 · 界面重构

Android 10 及以上；versionCode 24；Room 数据库 v6；备份格式 v3。

### 本版变化

- 采用低饱和薰衣草紫、雾白画布、白色描边卡片和柔和阴影，重做手机端总览、应用、应用详情、周期对比和设置页面。
- 使用大标题、说明文字、下划线视图切换、细比例条和悬浮底栏，统一浅色与深色主题。
- 应用页改为搜索优先的紧凑分组列表；应用详情增加记录天数、趋势、数据概览和每日时长分组。
- 修复应用占比条始终显示为满格的问题，比例条按实际应用份额绘制。
- 区分可用的零统计与缺失记录：可用零值显示为 0 分，没有记录才显示“未记录”。
- 对比图不再为可用的零值绘制短柱。
- 周期筛选补充选中状态语义；切换标签时列表返回顶部。
- 统计口径、数据库 v6、备份格式 v3 和 CSV 字段未改变。

### 验证与限制

全量 Preview 构建、170 项核心 JVM 测试和 125 项应用 JVM 测试通过；Lint 0 errors、15 warnings。交付包在隔离模拟器完成总览、应用排行、应用详情、今天零值、月对比、设置和深浅主题切换的实际页面复核，复核后崩溃缓冲为空。

新增 Compose 组件测试覆盖比例条像素宽度、零值/缺失值和按钮选中语义；它和现有界面流程测试在 Android 37 模拟器上均因测试框架反射调用已不存在的输入接口而在初始化阶段失败，未执行到业务断言，因此不计为通过。未执行真机覆盖安装、真实授权数据和长期后台验收。
