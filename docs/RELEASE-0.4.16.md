# 用时记 0.4.16

支持 Android 10 及以上。安装包版本代码为 45，数据库版本为 6，完整备份格式为 v3。

## 本版更新

- **新增分类页。** 底栏「分类」替换原来的「分析」。可以按今天、本周、本月或自选日期查看各类用时和应用明细。
- **分类占比环形图。** 圆心显示所选日期的累计用时，同色圆环和列表标出各分类的用时与占比。窄屏上下排列，宽屏并排显示。
- **默认与手动归类。** 常见应用自动归入学习、工作、社交、影音或游戏，其余归入其他。可手动修改或恢复默认。已有手动分类继续生效，历史用时按当前分类汇总。

## 覆盖升级

可以从上一正式版 0.4.14 直接覆盖安装。发布流程用两年合成记录验证覆盖升级，检查历史记录、原有手动分类和设置。结果见附件 `upgrade-check.json`。
