# 用时记 0.4.0 · 电脑用时与双向加密同步

Android 10 及以上；versionCode 29；数据库版本 6；完整备份 v3。

## 新增

- 设置中的云端同步支持双向：手机统计继续加密上传，开启「显示电脑数据」后才拉取 Hindsight 修改版发布的电脑应用用时。
- 新增「电脑用时」页面，默认隐藏；在「设置 → 电脑数据」开启「显示电脑数据」后，可从底部导航或总览页卡片进入。
- 支持多台电脑的设备切换、日期前后切换、应用排行、分类分布和最近七天趋势。
- 显示电脑设备名、平台、时区、首次/最后活动时间和同步状态。
- 开启电脑显示后，设置页提供「立即拉取电脑用时」，并显示电脑同步状态与上次成功时间。

## 数据口径

- 手机用时与电脑用时完全分开展示，不合并、不求和；两端重叠时间不会被当作用时相加。
- 电脑只发布每日应用汇总和分类汇总，不发布窗口标题、网址、截图、原始事件或 AI 总结。
- Hindsight 中标记为排除的记录不会发布。
- 未同步日期显示“尚未同步”，已发布但当天没有累计活动的日期显示“未记录”，两者都不显示为零用时。
- 电脑数据存入应用私有缓存，不写入手机统计数据库，不改变采集、去重或统计算法。

## 同步与安全

- 复用 0.3.19 的 WebDAV 地址、账号、应用专用密码和 256 位配对码，不需要新建账号。
- 手机与电脑使用不同命名空间和 AAD 前缀；密文不能跨路径或跨设备复用。
- 桌面先上传变化日文件，最后发布清单；手机按摘要增量下载，GCM、SHA-256 和累计校验失败时保留旧缓存。
- 只允许 HTTPS，禁止 URL 内嵌账号密码、查询参数和 fragment；不跟随重定向。
- 同步默认关闭；关闭后停止后续任务，不删除本地记录或云端历史。
- 「显示电脑数据」独立默认关闭，已有同步配置也不会自动开启；关闭时隐藏电脑入口与摘要，不再拉取电脑数据，保留已下载缓存。手机用时上传不受此开关影响。

## 配套桌面

需要 Hindsight Mobile 0.11.2-mobile.5 或更高修改版；原版 Hindsight 不识别本同步格式。
桌面侧栏「手机用时 → 设置」中保持“同时把电脑应用用时加密发布给手机”开启。

## 验证边界

- 手机 JVM：146 项通过，包含电脑协议解析、累计一致性、设备/日期校验和跨端加密向量。
- 桌面前端：471 项通过；TypeScript、ESLint 和 Vite 构建通过。
- 桌面 Rust：手机与电脑同步模块 11 项测试通过，含本地假 WebDAV 的发布端到端测试。
- 本次未在 Android 模拟器上完成新页面的逐项点击验收：当前环境的模拟器被用户目录 ACL 与 QEMU BIOS/ROM 路径问题阻塞。安装包已生成，但界面验收边界以实际说明为准。
- 未连接真实 WebDAV 服务做端到端传输；测试使用合成数据和固定加密向量。
