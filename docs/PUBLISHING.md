# 发布内容规则

## 可提交内容

- Android 应用源码和纯 Kotlin 统计核心。
- 使用合成数据的单元测试、隔离数据库测试与 SQLite 迁移检查。
- Gradle 配置、Wrapper、Room 数据库结构和必要的项目说明。

## 不得提交内容

- 真实使用记录、备份文件、数据库实例、报表导出或录制数据。
- 手机截图、录屏、设备型号与序列号、设备身份标识及个人账号信息。
- 个人姓名、联系方式、本机用户名、绝对开发路径与内部会话记录。
- 密码、访问令牌、私钥、签名证书、签名密钥库或本机 SDK 配置。
- 构建缓存、诊断日志、历史安装包、内部设计资料及其他无关文件。

发布副本通过文件白名单建立，未导入原工作区历史。开发日志和设备验收文档不属于发布内容；读取现有个人数据库的诊断测试也不纳入仓库。

每次发布应运行 `python tools/audit_public_tree.py`，并在提交前审查文件清单。扫描仅用于辅助人工审查，不应把忽略规则或关键词扫描视为绝对保证。

GitHub 托管页面会显示仓库所属账号，这是平台信息；提交作者使用项目身份，不写入本机 Git 用户资料。
