# 用时记 0.4.4 · 导出安全与发布可靠性修复

Android 10 及以上；versionCode 33；数据库版本 6；完整备份 v3。

## 本版更新

- **CSV 导出安全加固**：导出的应用名称或导入包名即使以制表符、回车、换行、空字符、空白后公式或全角公式符号开头，也会按普通文本转义，避免被表格软件误当作公式执行。普通名称、前导空格、引号与分隔符保持原有格式。
- **Release 构建可靠性**：清理环境不再因为强制引用本机私有签名文件而在打包阶段失败；无签名配置时生成未签名包，提供完整签名环境后使用指定身份构建。正式发布仍使用稳定签名并执行签名指纹比对。
- **云端回归修复**：GitHub Actions 模拟器启动前补齐 KVM 设备权限准备；验证流程新增完整 Release 打包检查，避免只验证代码压缩而漏掉签名和打包阶段错误。
- **文档修正**：修复更新记录中的历史验证链接，补回缺失的许可证与历史说明，并新增本轮源码检查和云端回归记录。

## 兼容说明

- 数据库版本（6）、完整备份格式（v3）与 WebDAV 同步协议保持不变。
- 支持从 0.4.3 直接覆盖安装，原有设置、统计历史和分类数据不受影响。
- 本轮不改变统计口径、权限配置或联网行为。
