# 用时记 0.3.19 · Hindsight 手机同步

Android 10 及以上；versionCode 27；数据库版本 6；完整备份 v3。

## 新增

- 设置中增加 Hindsight 手机面板连接配置，配套桌面修改版可自动拉取手机用时。
- WebDAV 地址要求 HTTPS；账号使用服务商应用专用密码。配对码仅在手机和自己的桌面端使用。
- 默认关闭同步。开启后每小时在非计费网络、电量非低时尝试上传；系统省电可能延迟。
- 手动立即同步允许使用移动网络。重新上传全部历史用于修复手动删除的云端文件。
- 只上传已保存的每日双指标汇总、应用名称与包名、分类和质量信息，内容在本机以 AES-256-GCM 加密。
- 本机配置使用 Android Keystore 包装保存；不上传密钥，不需要注册本项目账号。

## 数据口径

- 与现有主要使用、屏幕可见统计共用报表读取逻辑，不改采集或统计算法。
- 已确认、候选估计、未知、未闭合分别传递；未知不作为零用时，未闭合不计入累计。
- 不上传原始事件、诊断日志或截图；这不是完整备份或手机间双向恢复。
- 关闭同步不删除本地记录或云端文件；请继续保存完整备份。

## 配套桌面

需要 Hindsight Mobile 0.11.2-mobile.1，原版 Hindsight 不识别本同步格式。
桌面侧栏「手机用时」支持设备和日期选择、双指标、排行、分类、七日趋势与月历。
桌面默认每 5 分钟检查更新，需保持程序运行；手机关机、无网络或系统延迟期间不会实时更新。
