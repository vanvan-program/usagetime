# 手机与电脑加密同步

默认只在本机保存记录。云端同步为自愿启用功能，需要自己的 HTTPS WebDAV 服务和支持本协议的 Hindsight 修改版。

1. 在用时记「设置 → 自动同步 → 配置自动同步」填写 WebDAV HTTPS 地址、账号、应用专用密码和手机名称。
2. 保存配对码，在自己的 Hindsight 修改版「手机用时 → 设置」中填写相同的 WebDAV 配置和配对码。
3. 开启并保存手机自动上传。手机默认约每小时在非计费网络、电量非低时上传，系统省电可能延迟，也可手动立即同步。
4. 如需查看电脑用时，在手机「设置 → 电脑数据」开启「显示电脑数据」，并在 Hindsight 修改版开启电脑应用用时加密发布。

「显示电脑数据」默认关闭，已有云端配置不会自动开启。关闭时不显示电脑入口、总览摘要或电脑同步状态，也不发起电脑数据拉取。关闭后保留此前缓存，不删除本机记录或云端历史，手机用时上传继续按原配置执行。

配对码是解密密钥，不能公开分享。账号与密码填写在独立字段，不放进 URL。配置由 Android Keystore 保护，手机与电脑使用独立的云端命名空间及附加认证信息。

同步只传输加密的每日统计和设备清单，不包含原始使用事件、窗口标题、网址、截图或诊断日志。电脑和手机分别展示，不合并求和。同步不能代替完整备份或手机间恢复；换机或卸载前请导出完整备份。
