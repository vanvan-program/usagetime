# 用时记 0.4.17

支持 Android 10 及以上。安装包版本代码为 46，数据库版本为 6，完整备份格式为 v3。

## 本版更新

- **扩大自动分类覆盖。** 新增「浏览」「生活」「工具」，内置规则覆盖 300 个 Android 包名，包含常见浏览器、阅读应用、购物支付、地图出行、系统工具和 AI 助手。新规则在本地识别应用，可用于已有记录和新增记录。
- **手动归类优先。** 已有手动分类继续生效，应用归类中可随时恢复默认。分类页和桌面小组件会按当前归类汇总用时。
- **兼容已有备份。** V3 备份可保存新增分类，旧版本读取这些手动分类时会归为「其他」。

## 覆盖升级

发布流程从 0.4.16 正式安装包直接覆盖安装，核对两年合成历史、原有手动分类和设置。验证结果见附件 `upgrade-check.json`。
