# 用时记 0.4.5 · 应用内更新与刷新性能

Android 10 及以上；versionCode 34；数据库版本 6；完整备份 v3。

## 本版更新

- **应用内更新**：设置页检查到新版本后，可直接在应用内下载 APK 并交给系统安装器。下载过程显示进度、下载源、已下载大小与速度；单个来源失败时提示错误并自动切换下一个来源，也可取消或改用浏览器下载。
- **国内镜像源**：新增 ghfast.top、ghproxy.net、gh-proxy.com、github.moeyy.xyz 四个 GitHub 代理；检查更新与 APK 下载都支持回退，并可在「自动 / 国内镜像优先 / 仅 GitHub」之间切换。
- **增量刷新自适应重叠**：事件查询重叠从固定 2 天缩短为健康状态下的 30 分钟；首次采集、权限中断、时钟异常、空响应、长时间未补记以及每 6 小时深核对时回退 2 天，兼顾速度与迟到事件完整性。
- **报表缓存按范围失效**：补记后只清除窗口落在受影响范围内的报表缓存，未变化的历史报表继续复用，减少重复计算与界面等待。

## 兼容说明

- 数据库版本（6）、完整备份格式（v3）与 WebDAV 同步协议保持不变。
- 支持从 0.4.4 直接覆盖安装；统计口径、历史数据与分类设置不受影响。
- 新增 `REQUEST_INSTALL_PACKAGES` 与 FileProvider，仅用于把应用内下载的更新包交给系统安装器；未点击下载更新时不会使用。
- 更新检查与下载仅在手动操作时联网；默认使用 GitHub 官方源，失败后按设置回退到国内镜像。

- `:core` JVM 测试 186 项、`:app` JVM 测试 192 项、Python 发布工具测试 5 项与 SQLite 双层存储校验全部通过。
- Preview / Release 构建、设备测试源码编译与 Lint 通过；Android Lint 为 0 errors，其余 4 项为目标平台和依赖更新提醒。
- 正式安装包由发布工作流使用稳定签名构建，并与上一正式版执行签名指纹比对和覆盖升级数据保留检查；详细本地检查与未执行项见 [验证记录](VALIDATION-0.4.5.md)。
