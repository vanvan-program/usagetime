## 用时记 0.3.15 · 导出修复

Android 10 及以上；versionCode 23；Room 数据库 v6；备份格式 v3。正式发布。

### 本版变化

- 修复设置页切换“显示确定时间”后导出提示“暂无记录”的问题。
- CSV 导出按当前指标、旧版模式及累计口径重新查询，并将标签与数值绑定到同一快照。
- 保留最近实际报表的日期范围、详情和对比上下文，阻止示例报表作为真实记录导出。
- 新增 6 项导出回归测试。

### 验证与限制

170 项核心与 125 项应用 JVM 测试通过，全量 Preview 构建通过；Lint 0 errors、15 warnings；设备测试执行 0 项。本轮未重新审核时间统计准确性。

尚未完成本版真机覆盖安装、页面点击、后台运行及文档提供器验收。安装包沿用已有 Android Debug 开发签名，由 Preview 变体构建；正式 Release 状态不代表设备验收完成。签名与 0.3.12 一致，不能以同签名检查替代实际覆盖安装测试。

升级前请在应用内导出完整备份。遇到签名冲突请保留原安装，不要通过卸载处理。数据库 v6 与备份 v3 不支持交给旧版应用直接降级使用。

主要使用时间和屏幕可见时间为不同指标；未知不等于零使用。系统 API 无法可靠证明的时间不承诺精确。长期历史压缩后不支持精确还原旧小时或任意时区的部分日期。
