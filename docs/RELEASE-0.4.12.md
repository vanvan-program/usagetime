# 用时记 0.4.12

支持 Android 10 及以上。安装包版本号为 41，数据库版本为 6，完整备份格式为 v3。

## 本版更新

- **打开时优先显示已保存的统计。** 数据库恢复检查和后台任务初始化在后台执行，冷启动时为首页报表保留绘制时间，随后继续补记。
- **减少报表计算开销。** 按时间顺序合并使用区间，近期统计复用明细范围。回归覆盖累计时间、未知覆盖、未闭合时间和应用排序。
- **减少切换范围时的磁盘写入。** 当天未结束或自定义范围截断的小时、日、月报表使用内存缓存，完整周期继续保存到本地数据库。

## 覆盖升级

使用正式 APK 可从 0.4.11 覆盖升级。发布流程使用同一份安装包核对签名、历史记录和设置，结果见发布附件 `upgrade-check.json`。
