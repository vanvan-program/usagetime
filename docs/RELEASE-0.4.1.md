# 用时记 0.4.1 · 周月选择与电脑数据开关

Android 10 及以上；versionCode 30；数据库版本 6；完整备份 v3。

## 操作改进

- 周对比直接点选周一至周日的整周，支持跨月周、翻月和跳转年月。
- 月对比直接选择月份，支持切换年份。
- 提供本周、上周、本月、上月快捷入口；未来周期不可选，选中立即生效。

## 电脑数据默认关闭

- 在「设置 → 电脑数据」新增「显示电脑数据」，默认关闭。
- 开启后才显示电脑导航、总览摘要和电脑同步状态，并允许从已配置的 WebDAV 服务拉取电脑记录。
- 关闭后停止后续电脑拉取并保留此前缓存，手机统计上传不受影响；开关状态重启后保留。
- 请求及响应读取会检查开关和取消状态，避免快速关闭再开启后旧任务继续下载。

## 其他修复

- 重新打开同步设置时，已保存且启用的配置可直接同步，不需要重复保存。
- 授权页说明更新为默认本机保存、云端同步自愿开启。
- 电脑同步校验增加单项用时和分类数量边界，拒绝累计数值溢出的异常记录。
- 包含此前本地开发的手机加密上传与电脑加密拉取功能；配置方法见同步说明。

未在实体手机或真实 WebDAV 服务执行本次端到端验收。发布验证结果见 `VALIDATION-0.4.1.md`。
