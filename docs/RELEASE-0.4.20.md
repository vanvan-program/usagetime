# 用时记 0.4.20

支持 Android 10 及以上。版本代码 49，数据库版本 6，完整备份格式 v3。

## 统计性能

- 查看数月的使用记录时，应用排行可以直接定位到每个应用首次出现的日期。新装应用出现在统计周期中后段时，也能快速汇总。用时相同的应用沿用原有排名顺序。
- 刷新报表、记录窗口事件和增量补记时，需要最近记录时间的步骤只读取时间戳，减少数据库读取量。

## 性能实测

在同一台 Android 16 模拟器上，用包含 208 个应用、跨度 128 天的合成历史交替测试优化前后的 Debug 构建。每个版本采样四轮，每轮预热一次，再测量八次报表计算。计算耗时中位数从 66.1 毫秒降至 32.2 毫秒，缩短约 51%。每次均逐字段核对了报表结果，包括应用排名。计时范围仅包含报表计算。
