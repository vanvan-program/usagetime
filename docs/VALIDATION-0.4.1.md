# 用时记 0.4.1 发布验证

## 版本与兼容

- versionName：0.4.1；versionCode：30。
- 数据库版本维持 6，完整备份格式维持 v3。
- 发布安装包沿用上一正式版 0.3.18 的签名身份，不切换签名。

## 检查与修复

- 周选择器直接按整周选择，月选择器直接按月份选择；当前周期继续保留跨午夜跟随与同期进度行为。
- 限制从往年返回今年时的可见月份，避免打开未来的空月份。
- 电脑数据显示默认关闭；后台、手动和页面刷新均由同一设置控制。
- 电脑请求和响应读取检查开关及任务取消状态，旧任务不能因快速关闭再开启而继续后续请求。
- 重新进入同步设置时保留已保存配置的可操作状态。
- 修正授权页联网说明；默认本机保存，云端同步自愿启用。
- 限制电脑日记录单项用时与分类数量，拒绝累计数值溢出。

## 本地验证

- 统计核心 175 项、应用 JVM 153 项测试通过，包含跨月周、闰月、当前周期跟随、取消请求、加密路径绑定、异常累计值和 HTTPS 配置校验。
- Preview 构建、Android 测试包编译与 Android Lint 通过。
- 隔离设备上的电脑开关、关闭时跳过配置与请求、云端配置前提及 Keystore 加密保存共 5 项测试通过。
- Python 发布工具 4 项测试通过，SQLite 迁移、一致性、增量回放和汇总检查通过。
- 隔离模拟器检查默认隐藏、开启/关闭入口及重启后的状态保留。
- 隔离模拟器使用两年合成历史执行 0.3.18 → 0.4.1 覆盖升级；八张历史表的行数与内容摘要保持一致，SQLite 完整性及主题、确认时间和自动补记设置保留。

## 信息披露检查

- 发布源码通过白名单整理和公开树审计，不包含工作区日志、内部验收资料、截图、真实数据库、备份、报表、签名密钥库或本机工具配置。
- 安装包与源码压缩包检查私人密钥、访问令牌、本机用户名路径和开发目录，不将这些内容作为发布附件。
- 合成测试中的固定密钥、账号、用时及设备标识仅为测试样本，不是实际账户或个人使用数据。
- 云端配置由 Android Keystore 保护；传输要求 HTTPS，账号密码不嵌入 URL，不跟随重定向；同步内容使用 AES-GCM 加密并绑定路径和命名空间。

## 验证边界

- Android 37 本地环境的现有 Espresso 依赖存在兼容问题，新增 Compose 界面测试已编译但未完成自动断言；周月选择与设置显隐通过模拟器控件树直接操作检查。GitHub 工作流保留原有存储回归范围。
- 未在实体手机、真实 WebDAV 服务或不同厂商桌面执行本次端到端验收。
- 扫描和测试不等同于独立的全面安全审计。正式附件提供源码、安装包及 SHA-256 校验文件，便于复核。
