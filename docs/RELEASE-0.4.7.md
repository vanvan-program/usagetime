# 用时记 0.4.7

支持 Android 10 及以上。安装包版本号为 36，数据库版本为 6，完整备份格式为 v3。

## 本版更新

- **可选择更新源。** 在「设置 → 关于用时记 → 更新源」中选择自动、镜像优先或仅 GitHub 官方。应用会记住所选线路，并在检查时显示实际使用的来源。
- **修复镜像查询失败。** 检查更新使用 GitHub 官方或 gh-proxy.com。ghfast.top 和 ghproxy.net 继续提供 APK 下载，下载时会核对发布信息中的 SHA-256 校验值。
- **可离线查看版本更新介绍。** 打开「设置 → 关于用时记 → 版本更新介绍」，即可查看当前安装版本的更新内容。

## 覆盖升级

已安装 v0.4.6 正式版的用户可直接覆盖安装。发布流程在公开安装包前比对正式签名，并在安卓模拟器里验证覆盖安装后保留历史记录和设置。验证结果随发布提供，见附件 `upgrade-check.json`。
