# 用时记 0.3.17 · 分类与时间分析

Android 10 及以上；versionCode 25；Room 数据库 v6；备份 v3。

## 新增

- 总览和应用页支持学习、工作、社交、影音、游戏、其他六类统计；在应用详情修改分类，展开分类可查看所属应用。
- 分类不会改写使用历史；未归类的应用计入其他，示例模式的调整与真实分类隔离。
- 新增“分析”入口：当天时间线保留已确认、候选估计、未知、未闭合与没有保存明细的区别，不将空白区间认定为零使用。
- 新增月历与年度热力图，沿用当前指标、累计开关和旧版口径。月历支持点击日期进入统计，年度图可跳转月份。
- 月历明确区分未记录、可用零值、部分记录和未来日期；年度图横向滑动查看全年。
- 新增今日用时桌面小组件，显示真实记录、前三项分类、最近补记时间。后台更新受系统调度影响。
- 备份 v3 新增可选 `app_categories` 扩展；旧备份继续兼容，导入分类时优先保留本机已设置的分类。
- 保存当前统计指标偏好；小组件沿用同一口径。

## 发布与数据保护

- 新增 GitHub Actions 回归和正式发布流程，检查标签/源码/APK 版号、升级版号递增和签名一致性，生成源码与校验附件。
- 新增旧版 APK 覆盖升级脚本，检查两年合成历史及设置保留；仅允许专用模拟器执行。
- 修复压缩备份解析时 JSON 结束检查可能掩盖 gzip 尾部缺失的问题。
- 修复深色卡片默认文字颜色，避免日期标题出现低对比黑字。

## 使用说明

在“应用”中打开一个应用，点击分类按钮调整归类。在底部“分析”切换当天时间线、月历和年度热力图。在“设置 → 桌面小组件”添加小组件，也可从桌面的小组件列表添加。

当天时间线展示已保存的近期明细；长期日汇总无法反推出旧时段。屏幕可见的不同应用允许重叠，分类累计也不等同于手机亮屏时长。

自动发布首次运行前须由仓库维护者配置原签名身份对应的加密 Secrets，详见 [自动发布与升级验收](RELEASE-AUTOMATION.md)。本地模拟器验收不代表真机或长期后台保证。
