## 用时记 0.3.14 · 可信状态说明

Android 10 及以上；versionCode 22；Room 数据库 v6；备份格式 v3。正式发布。

### 本版变化

- 在“数据可信状态”标题后添加问号按钮，点击后显示说明弹窗。
- 保留已确认、候选估计、无法确定、未闭合四类时长摘要。
- 沿用 0.3.13 架构与数据格式。

### 验证与限制

发布前离线 Preview 构建与 Lint 通过，170 项核心与 119 项应用 JVM 测试通过；重建 DEX 与原安装包完全一致。本版未单独重跑 SQLite 回归，未执行设备界面验收。

尚未完成本版真机覆盖安装、页面点击、后台运行及文档提供器验收。安装包沿用已有 Android Debug 开发签名，由 Preview 变体构建；正式 Release 状态不代表设备验收完成。签名与 0.3.12 一致，不能以同签名检查替代实际覆盖安装测试。

升级前请在应用内导出完整备份。遇到签名冲突请保留原安装，不要通过卸载处理。数据库 v6 与备份 v3 不支持交给旧版应用直接降级使用。

主要使用时间和屏幕可见时间为不同指标；未知不等于零使用。系统 API 无法可靠证明的时间不承诺精确。长期历史压缩后不支持精确还原旧小时或任意时区的部分日期。
