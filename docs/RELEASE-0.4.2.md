# 用时记 0.4.2 · 品牌图标统一

Android 10 及以上；versionCode 31；数据库版本 6；完整备份 v3。

## 图标更新

- 桌面图标改为与 app 内顶部品牌标一致的渐变圆角时钟：紫色、粉色到橙色渐变，中央为白色时间图标。
- 使用 Android 自适应图标，背景延伸到遮罩边缘，前景时钟保持在安全区内，适配圆形、圆角方形等不同启动器遮罩。
- 补充 Android 13 及以上的主题单色图标，跟随系统壁纸和主题着色。
- 旧式矢量图标同步更新，供不支持自适应图标的启动器、图标预览和系统旧界面使用。

## 兼容说明

- 功能、统计口径、数据库版本、备份格式和同步协议均无变化。
- 可直接覆盖安装 0.4.1，已保存的设置、统计数据、电脑缓存和同步配置不受影响。

## 验证

- 统计核心 175 项、应用 JVM 153 项测试通过，Android Lint 与 Preview 构建通过。
- 按实际矢量几何生成 32、48、72、128 px 多尺寸预览，检查圆形与圆角方形遮罩下的辨识度。

本次未完成实体手机或真实启动器截图验收；发布验证细节与边界见 `VALIDATION-0.4.2.md`。
