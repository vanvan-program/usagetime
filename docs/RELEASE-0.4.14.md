# 用时记 0.4.14

支持 Android 10 及以上。安装包版本代码为 43，数据库版本为 6，完整备份格式为 v3。

## 本版更新

- **修复更新公告排版。** 检查更新和当前版本介绍都支持 Markdown 标题、列表、粗体、代码和链接，以及 GitHub 的表格、任务列表和删除线。长公告可滚动读到结尾。
- **改善窄屏和大字布局。** 将授权和示例数据入口移到首次使用说明前部，设置中的统计选项会按可用宽度换行。
- **提高界面可读性。** 更新弹窗使用不透明底色，改善底栏、主要按钮和深色状态栏的文字对比度。

## 覆盖升级

正式发布流程在 Android 模拟器上从 0.4.13 的正式 APK 覆盖安装，核对历史记录和设置。验证结果见发布附件 `upgrade-check.json`。
