# 用时记 0.3.18 · 多款桌面小组件

Android 10 及以上；versionCode 26；数据库版本 6；备份 v3。

## 新增

- 桌面小组件扩展为五款，按桌面空间选择：
  - 用时速览 2×1：今日总用时和最近补记时间。
  - 今日概览 3×3：总用时、昨日同期、24 小时走势、前三应用和统计口径。
  - 应用排行 4×3：前五应用的用时、占比和排行条。
  - 分类分布 3×2：分类环图、前三分类和其余分类汇总。
  - 七日趋势 4×2：七天柱状图、每日数值、累计和已记录日均。
- 今日概览在 3×3 空间内显示三行应用排行，信息量不再只有总用时和更新时间。
- 应用行、图表和底部说明补充无障碍描述；点击小组件可进入对应页面。
- 应用排行中的单个应用可进入应用详情；七日趋势打开最近 7 天。
- 刷新按钮和系统更新改为立即渲染，后台 WorkManager 仅作为补充，减少桌面停留在“正在读取”的时间。

## 修复

- 修复首次添加或调整尺寸时，系统同时给出最小/最大尺寸导致 3×3 被错误降级成“用时速览”的问题。
- 修复大字体下底部补记时间被裁切的问题。
- 修复无权限或暂无记录时小组件中间留白过大的问题，改为居中提示。
- 小尺寸、大字体和高度不足时继续保留总用时，不伪造零值，不把未知区间写成 0。

## 数据与口径

- 小组件只显示本机已保存的真实记录，不把示例数据放到桌面。
- “未记录”和“0 分”严格区分；部分记录显示“部分记录”，不错误声称同比增加或减少。
- 分类沿用应用分类设置；未归类应用计入“其他”。
- 小组件沿用当前统计指标、旧版历史开关和确认时间开关。

## 使用说明

在“设置 → 桌面小组件”选择款式并添加，也可从系统桌面长按空白处进入小组件列表。右上角按钮立即刷新；系统定时刷新仍受省电策略和 WorkManager 调度影响。补记新数据请打开用时记。

## 验证边界

- 已在专用 Android 模拟器完成小组件渲染、深浅主题、尺寸降级、大字体、空状态和点击恢复测试。
- 已在模拟器桌面实际添加今日概览 3×3，确认首次添加不再降级为用时速览，并确认刷新后立即更新。
- 未在物理手机执行安装、权限授权和长期后台验收；模拟器结果不代表所有厂商系统的桌面行为。
