# 用时记

用时记是一款 Android 10 及以上版本的手机应用使用时间统计工具。它读取系统的应用使用记录，在本地计算并保存你每天在哪些应用上花了多少时间，生成小时、日、周、月的趋势图表和应用排行，帮助你了解自己的手机使用情况，例如每天主要把时间花在了哪些应用、过去一周或一个月的使用变化。

所有数据都保存在手机本机：没有账号，没有联网权限，不上传任何使用记录。应用提供本地备份导出导入，换机或卸载前可以先导出备份。

当前版本：0.3.10，versionCode 18，数据库版本 5。安装包可从 [Releases](../../releases) 下载，提供四架构整合包和四种单架构包，五选一安装即可。

完整版本历史见 [更新记录](CHANGELOG.md)，覆盖 0.1.0 至 0.3.10。

## 功能

- 主要使用时间、屏幕可见时间两种统计口径，以及旧版历史，在设置的“记录与统计”中选择。
- 默认展示推断时间，可在设置中开启确定时间。
- 按小时、日、月汇总，支持趋势、应用排行、搜索、详情和周期对比。
- 有容量限制的报表缓存，数据变化后失效；图表样式、搜索和排序复用已加载的结果。
- 原始事件本地保存、增量补记、失败重试、重启和更新后调度补记。
- 本地 JSON 备份导入导出、CSV 导出、数据库恢复保护和隔离的示例模式。

## 统计口径

**主要使用时间**：估计你真正把时间花在了哪个应用上。它根据可获得的应用生命周期和窗口焦点证据归属，第三方应用的生命周期通常只能支持推断；证据不足或多窗口冲突时保留未知状态。

**屏幕可见时间**：按应用累计处于可见状态的时间，多个应用可能重叠（例如分屏或画中画），不能与系统亮屏时长直接等同。

确定、推断、未知与暂定状态表示证据质量，不代表系统提供了完整的历史记录。应用未运行时，Android 仍可能保留近期使用事件，后续可以补记；事件保留期限和后台任务执行受到系统限制。首次安装、权限中断或长期未补记可能存在无法恢复的缺口。

## 构建

需要 JDK 21、Android SDK 37 和 Build Tools。配置 `JAVA_HOME`、`ANDROID_HOME`；也可通过本地 `local.properties` 配置 SDK 路径，该文件不得提交。

Windows PowerShell：

```powershell
./build-local.ps1
python tools/verify_dual_storage.py
```

脚本通过 Gradle Wrapper 构建 Preview APK、编译测试、运行 125 项核心和 21 项应用 JVM 测试并执行 Lint。SQLite 检查脚本运行 24 项迁移和一致性检查。Android 仪器测试需要独立测试设备或模拟器，不应对个人日常数据库执行测试。

其他平台可使用 Wrapper：

```sh
sh gradlew :app:assemblePreview :core:test :app:testDebugUnitTest :app:lintDebug
python3 tools/verify_dual_storage.py
```

输出位于 `app/build/outputs/apk/preview/`。Preview 使用本机生成的开发签名，不保证可以覆盖其他签名的安装包。Release 构建未配置签名，发布者需自行安全配置。

## 隐私与数据

应用无需账号，没有联网权限。使用记录保存在本机；卸载前应导出备份。

Git 源码树仅包含源码、数据库结构、合成测试和必要文档，不包含个人使用记录、个人手机信息、手机截图、导出备份、数据库实例、诊断日志、签名密钥或历史安装包。数据库结构 JSON 只描述表和字段，不包含数据库记录。测试使用人工构造的数据，示例模式使用程序生成的数据。Release 附件提供单独审查的安装包、源码压缩包及 SHA-256 校验文件。
